# About

I'm a backend and platform engineer building AI-native workflows with checkpoints, boundaries, and cross-model review.

My path has not been a straight line. I started with early web building, spent years doing technical work inside regulated systems, went through a full market cycle that taught me to respect risk, then moved through data science into backend and platform engineering. That path is what shapes how I think about AI today: treat complex environments like experiments, validate assumptions before trusting them, build tools instead of relying on memory, and define boundaries before speed turns into risk.

My work is about making strong AI models useful in real engineering settings, where reliability matters more than speed alone. I care about context handoff, controlled loops, explicit boundaries, and review systems that make AI work easier to trust.

I'm currently building **Handoff Reader**, a local-first CLI that turns repository evidence into a portable, validated handoff artifact for AI-native development workflows.

I write about AI-native engineering workflows, engineering judgment, risk, and systems thinking.
